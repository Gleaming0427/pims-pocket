Suppression de compte — Pims Pocket

Cette page explique comment demander la suppression de votre compte Pims Pocket et des données associées.

1. Suppression complète du compte parent

La suppression du compte parent entraîne la suppression définitive de toutes les données associées à votre famille : votre compte, les comptes de vos enfants, l'historique des transactions, les missions, les objectifs d'épargne et les badges.

Pour supprimer votre compte :

  1. Ouvrez l'application Pims Pocket
  2. Connectez-vous avec votre compte parent
  3. Allez dans Réglages → Sécurité
  4. Appuyez sur "Supprimer mon compte"
  5. Confirmez avec votre mot de passe

Les données sont supprimées immédiatement. Aucune donnée n'est conservée après la suppression.

2. Suppression du compte d'un enfant

Vous pouvez supprimer le compte d'un enfant sans supprimer votre compte parent. Rendez-vous dans la fiche de l'enfant concerné, puis appuyez sur "Supprimer l'enfant". Toutes les données de cet enfant (transactions, missions, objectifs, badges) seront supprimées définitivement.

3. Données supprimées

La suppression d'un compte entraîne l'effacement définitif des données suivantes :

  • Adresse email (parent)
  • Prénom (parent et enfants)
  • Date de naissance (enfants)
  • Historique des transactions
  • Missions et récompenses
  • Objectifs d'épargne
  • Badges
  • Paramètres de notification

4. Contact

Pour toute question sur la suppression de vos données, contactez-nous à privacy@pimspocket.app. Nous répondons dans un délai maximum de 30 jours.
