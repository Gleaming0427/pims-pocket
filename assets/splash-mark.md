# Splash mascot

`splash-mark.png` is the transparent launch-screen mascot, edited from `icon.png`
using the built-in imagegen tool. The launcher icon remains separate.

## Generation prompt

Use case: background-extraction. Asset type: transparent PNG brand mascot for the Android launch splash of Pims Pocket. Input image is the edit target. Preserve the existing pink 3D piggy bank identity, rounded shape, three-quarter pose, face, ears, coin slot, feet and soft rendering. Remove the entire turquoise/pink gradient background and floor: true transparent alpha with clean edges, no colored halo, no square or circular backing plate. Center the complete pig on a square canvas with generous equal transparent padding; the pig should occupy about 65% of canvas width and height, entirely contained within the central safe area for an Android splash icon. No text, no lettering, no extra objects, no coin added, no watermark. Keep all parts visible without cropping.
